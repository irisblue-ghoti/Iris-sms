# 接码助手 - Chrome 浏览器扩展

一个方便的短信验证码接收助手，可在任何网页使用。

## 功能特点

- **悬浮按钮**: 在每个网页右侧显示悬浮按钮，可拖动调整位置
- **侧边栏面板**: 点击按钮打开侧边栏，不影响当前页面
- **快速登录**: 支持邮箱注册和登录
- **国家/服务选择**: 支持全球100+国家，主流APP服务
- **实时接码**: 一键获取号码，实时接收验证码
- **一键复制**: 手机号和验证码可一键复制
- **余额充值**: 支持支付宝、微信充值

## 安装步骤

### 方法一：Chrome 浏览器安装

1. **打开扩展管理页面**
   - 在 Chrome 地址栏输入: `chrome://extensions/`
   - 或者点击菜单 → 更多工具 → 扩展程序

2. **开启开发者模式**
   - 在页面右上角找到「开发者模式」开关
   - 点击开启（变成蓝色）

3. **加载扩展**
   - 点击左上角「加载已解压的扩展程序」按钮
   - 在文件选择器中找到并选择 `browser-extension` 文件夹
   - 点击「选择文件夹」

4. **安装完成**
   - 扩展图标会出现在浏览器工具栏
   - 如果没有显示，点击工具栏的拼图图标，将「接码助手」固定

### 方法二：Edge 浏览器安装

1. 在地址栏输入: `edge://extensions/`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择 `browser-extension` 文件夹

## 使用方法

### 方式1: 点击扩展图标

1. 点击浏览器工具栏的扩展图标
2. 在弹出窗口中点击「打开接码面板」
3. 侧边栏会在浏览器右侧打开

### 方式2: 点击悬浮按钮

1. 在任何网页右侧会显示一个蓝色圆形按钮
2. 点击按钮打开侧边栏
3. 按钮可以上下拖动调整位置

### 接码流程

1. **登录账号**: 首次使用需要登录（没有账号可先注册）
2. **选择国家**: 在下拉框选择需要的国家
3. **选择服务**: 选择要接收验证码的APP/服务
4. **获取号码**: 点击「获取号码」按钮
5. **复制号码**: 获取到号码后，点击复制按钮
6. **接收验证码**: 在目标网站使用该号码，然后回到扩展等待验证码
7. **复制验证码**: 收到验证码后，点击复制即可使用

## 配置说明

### 修改后端地址

如果后端服务不在 `localhost:3000`，需要修改以下文件：

1. **src/sidepanel.js** - 第1行的 `API_BASE`
   ```javascript
   const API_BASE = 'https://your-domain.com';
   ```

2. **src/popup.js** - 修改网页版链接

3. **manifest.json** - 修改 `host_permissions`
   ```json
   "host_permissions": [
     "https://your-domain.com/*"
   ]
   ```

## 常见问题

### Q: 侧边栏打不开？
A: 请确保 Chrome 版本在 114 以上，旧版本不支持 Side Panel API。

### Q: 悬浮按钮不显示？
A: 检查扩展是否正确安装，或尝试刷新页面。

### Q: 登录失败？
A: 确保后端服务已启动（`http://localhost:3000`）。

### Q: 如何更新扩展？
A: 在扩展管理页面点击「刷新」按钮，或重新加载扩展。

## 系统要求

- Chrome 114+ 或 Edge 114+
- 后端服务正常运行

## 隐私说明

- 扩展只与配置的后端服务通信
- 登录信息保存在浏览器本地存储
- 不收集任何用户浏览数据
